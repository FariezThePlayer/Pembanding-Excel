Pembanding File Excel

Unggah File 1 dan File 2. Sistem akan membandingkan keduanya dua arah: File 1 → File 2 dan File 2 → File 1, sehingga setiap sisi bisa dicek dari perspektif lawannya. Jika Anda punya template/skeleton, unggah di kotak Template / Skeleton; bila tidak ada, sistem akan mencoba mengenali template dari isi file secara otomatis. Perbandingan dan tampilan tabel akan mengikuti header kolom dan header baris (kolom A) dari skeleton/template yang dipakai, atau dari header umum yang terdeteksi dari file unggahan bila tidak ada skeleton.
